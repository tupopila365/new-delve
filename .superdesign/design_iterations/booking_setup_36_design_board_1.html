Accessibility annotations

  • All controls labeled; 44px minimum targets on counters, seats, CTAs.
  • Visible :focus-visible ring using focus token (light brand / dark #C7ACFF).
  • Calendar keyboard: arrow keys between days; status not by color alone (text, patterns, aria-label).
  • Live region announces price and availability changes (see #liveRegion).
  • Seat maps ship a text alternative list of selected/available seats.
  • Error summary at top of form when Continue blocked; associate fields with aria-describedby.
  • prefers-reduced-motion disables non-essential motion.
  • Contrast: primary button on light uses #5F2FC9; dark mode primary #8C52FF on dark stone.
