    Accessibility annotations

    • All controls labeled; 44px minimum targets on choices, CTAs, accordion headers.
    • Visible :focus-visible ring using focus token (light brand / dark #C7ACFF).
    • Error summary at top when Continue blocked; associate fields with aria-describedby / aria-invalid.
    • Live region announces validation, branch switches, and continue/back actions.
    • Document numbers masked in summaries; full values only in secure form fields.
    • Accessibility language is respectful — assistance options, no diagnosis forcing.
    • prefers-reduced-motion disables non-essential motion.
    • Contrast: primary button on light uses #5F2FC9; dark mode primary #8C52FF on dark stone.
